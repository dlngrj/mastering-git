# Git & GitHub Masterclass Laboratory

[![Git](https://img.shields.io/badge/Git-F05032?style=for-the-badge&logo=git&logoColor=white)](https://git-scm.com/)
[![GitHub](https://img.shields.io/badge/GitHub-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/)

A comprehensive repository containing practical exercises, workflow experiments, and hands-on scenarios completed during Git and GitHub bootcamp courses.

---

## 📌 Core Competencies Developed

* **History & Commit Management:** Amending commits, interactive rebasing, squashing commits, and rewording commit messages.
* **Branching & Merging:** Feature branch workflows, 3-way merges vs. fast-forward merges, and resolving complex merge conflicts.
* **State Control:** Working with the staging index, stashing uncommitted changes, resetting (`git reset`), and reverting commits safely.
* **Remote Collaboration:** Managing remote branches, pushing/pulling changes, and handling upstream tracking.
